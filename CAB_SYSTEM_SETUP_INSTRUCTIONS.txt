CAB BOOKING SYSTEM - SETUP INSTRUCTIONS
===================================================

STEP 1: Create Database Tables
--------------------------------
1. Open phpMyAdmin in your browser
2. Select your database (travhub_db)
3. Go to the SQL tab
4. Copy and paste the entire contents of: setup_complete_cab_system.sql
5. Click "Go" to execute

This will create:
- cab_bookings table (stores all cab booking data)
- Add max_persons column to cab_route_pricing table

STEP 2: Verify Installation
----------------------------
After running the SQL:

1. Check the sidebar menu in admin panel, you should see:
   - Cab Routes
   - Cab Bookings
   - Cab Reports

2. Test the booking page:
   Visit: http://localhost/tour/cab-route-details.php?route_id=8
   (Replace 8 with an actual route ID from your database)

3. Admin Pages Available:
   - admin/cab-routes.php - Manage cab routes
   - admin/cab-bookings.php - Manage bookings
   - admin/cab-reports.php - View reports and statistics

FEATURES INCLUDED:
------------------
✓ Cab route details page with booking form
✓ Trip type selection (One Way / Round Trip)
✓ Automatic passenger capacity validation
✓ Booking management in admin panel
✓ Status updates (Pending, Confirmed, Completed, Cancelled)
✓ Payment status tracking (Pending, Paid, Refunded)
✓ Comprehensive reports with date filters:
  - Total bookings and revenue
  - Bookings by route
  - Bookings by cab type
  - Payment status breakdown
  - Trip type breakdown
  - Daily booking trends
✓ Print-ready report layout

TROUBLESHOOTING:
----------------
If you see "Table doesn't exist" errors:
- Make sure you ran the SQL file in phpMyAdmin
- Check that you selected the correct database

If route page shows no cabs:
- Make sure the route has pricing configured in admin/cab-route-pricing.php

For any other issues, check the debug page:
http://localhost/tour/debug-route.php?route_id=8
