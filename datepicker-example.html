How to Use

1. Include Required Files:

<!-- Flatpickr CSS -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/flatpickr/dist/flatpickr.min.css">

<!-- Enhanced Datepicker CSS -->
<link rel="stylesheet" href="assets/css/attractive-datepicker.css">

<!-- Flatpickr JS -->
<script src="https://cdn.jsdelivr.net/npm/flatpickr"></script>

<!-- Enhanced Datepicker JS -->
<script src="assets/js/enhanced-datepicker.js"></script>

2. Features:

  • ✨ Floating labels with smooth animations
  • 🎨 Modern gradient design matching your theme
  • 📱 Fully responsive on all devices
  • ⚡ Smooth hover and focus effects
  • 🎯 Click anywhere on wrapper to open calendar
  • ⌨️ Press Enter to open calendar
  • 🔧 Customizable date formats and restrictions
  • ♿ Accessibility compliant
  • 🔄 Auto-initializes for dynamic content

3. Data Attributes:

  • data-date-format: Internal date format (Y-m-d, d/m/Y, etc.)
  • data-alt-format: Display format (F j, Y shows "January 1, 2024")
  • data-min-date: Minimum selectable date ("today", "2024-01-01", etc.)
  • data-max-date: Maximum selectable date ("today", "2024-12-31", etc.)
